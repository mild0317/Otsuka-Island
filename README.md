# 塚博士的浮空島

浮空島互動測試版。純 HTML、CSS、JavaScript，無需建置工具；素材、星表與天文計算程式皆隨專案本地載入。

第 92 版將星盤的透視中心由畫面寬度 70% 改為中央，修正偏移鏡頭造成的左右放大比例差異。真實星位與同一套恆星時保留，日月的獨立左右升落路徑不變。`node check-star-coordinates.mjs` 檢查光軸置中、左右相同角度的投影比例，以及星位參考值。

第 91 版新增唯讀「播放日期」，以完整年月日顯示目前播放中的日期，隨時間倍率跨午夜換日；不提供日期編輯。真實星空仍依指定觀測座標、播放日期與時間變化。日月的畫面路徑改為獨立的場景動畫：太陽 06:00 自最左下雲海天際線升起、18:00 在最右下落下；月亮 18:00 升起、隔日 06:00 落下。兩者單向由左往右通過天空，高點略靠右以避開鐘塔；月相仍隨日期變化。這些日月路徑不代表真實天文方位。`node check-sky-orbits.mjs` 檢查左右升落點、與星盤無關的路徑、跨午夜連續性、唯讀日期換日、星空每日位移及手機／4K 顯示。

第 90 版將觀測位置改為指定的 **25°00′45.4″N、121°27′48.7″E**（25.012611111°N、121.463527778°E）。天空固定朝東南方中高空，涵蓋日月經過的區域，使用同一個固定透視視窗，不追蹤天體移動。移除日期與方位選擇；載入自動採用當天日期，既有時間倍率仍可自然推進日期。星座連線開關保留。`node check-star-coordinates.mjs` 使用同位置的 USNO 參考資料核對恆星與日月；`node check-sky-orbits.mjs` 檢查指定座標、固定視野、日月可見時段與手機／4K 構圖。

第 89 版將整片天球的廣角投影改為固定方位的局部透視視窗，預設面向東方，水平視角不超過 85°；直式手機使用較寬鏡頭保留日出構圖。太陽、月亮與星座共用台北觀測位置、日期時間及視角；日月位置與月相由本地 Astronomy Engine 計算，取消原本擠在畫面內的橢圓路徑。天體升高或移至其它方位時會自然離開畫面，切至西方可觀察日落。日月光暈、星光閃爍與雲海遮擋保留。`node check-star-coordinates.mjs` 同時核對恆星與日月的 USNO 參考位置；`node check-sky-orbits.mjs` 檢查有限視野、直線天際、日出／日落、天體離開視野及跨午夜連續性。計算程式來源與授權見 [astronomy-sources.md](assets/vendor/astronomy-sources.md)。

第 88 版改用本地打包的 41,411 顆 XHIP 恆星資料，依台北經緯度與島上日期、台灣時間計算星空。恆星、銀河依恆星時轉動，每晚與不同季節呈現不同可見星區；星光閃爍、流星與天氣仍各自變化，真實星座的相對排列不隨機打散。工具選單新增「真實星圖」，可選日期、面向北／東／南／西，並切換星座連線與中文名稱。調高時間倍率可觀察星空轉動；風速仍獨立控制雲層。星圖包含近似歲差與地平座標換算，不含行星、折射或精密星曆；日月保留原場景軌跡。資料、授權與計算來源見 [star-catalog-sources.md](assets/star-catalog-sources.md)。`node check-star-coordinates.mjs` 核對 25 顆 USNO 亮星參考位置、恆星日與跨午夜連續性；`node check-star-map.mjs` 檢查日期、季節、方位、連線、倍率轉動、手機及 4K 顯示。

第 87 版將風向限制為「向左／向右」，控制項改為兩個方向按鈕，風速範圍擴大至 0–20×。自動風速與隨機風向仍可分別切換；隨機換向間隔至少約三分鐘，先減緩至靜風再沿水平方向反向，不產生上下漂移。時間倍率維持只影響天色，風速與雲移動獨立控制。`node check-wind-controls.mjs` 與 `node check-cloud-wind-direction.mjs` 檢查 20× 上限、左右方向、隨機換向間隔、各層實際雲紋位移、零風速及桌機／手機控制項。

第 85 版統一各層雲的風向：移除前景雲霧的水平翻轉與雲層容器原有的左右擺動，並修正垂直位移的貼圖長寬比。天空薄雲、遠處雲海與前景雲霧均朝控制項的「吹向」移動，遠近保留速度差；雲海在固定高度範圍內流動，維持平均天際線。每日天氣與局部聚散只改變雲形、濃淡，不再額外推動雲層逆風漂移。切換風向時延續既有累積位置，背景運算持續交替發布完整影格，調整風向控制時雲不會因丟棄影格而停住。

第 84 版讓太陽與月亮各自沿雲海天際線升降：場景中的太陽在 06:00 從右側雲海升起、18:00 於左側落下；月亮則在夜間走獨立軌跡，清晨從另一側落下。正午太陽保留已確認的位置與光暈，接近地平線時增加暖色散射；雲海自然遮擋低於天際線的光源，避免清晨高空原地由月亮淡換成太陽。這是場景的視覺日夜循環，未使用天文星曆。`node check-sky-orbits.mjs` 檢查升降方向、跨午夜連續性、相反方位的清晨日月，以及桌面／手機／4K 的天際線位置。

第 83 版將夜間星光從最長邊 1536 像素的天空快取中分離。細星依螢幕尺寸與像素密度直接繪製，支援 4K；遠方星塵與不規則暗帶、中距離星群、少數帶光學暈光及繞射光芒的亮星分層呈現，各層有不同的微量視差及獨立閃爍。夜空加深至近黑靛藍，保留雲層遮星、月相、流星及動態暫停。已確認的日間雲層與太陽效果不變。`node check-star-depth.mjs` 檢查原生像素密度、分層視差、亮星光芒與暫停；`node check-night-sky.mjs` 檢查日夜、遮星、時間倍率及手機／4K 畫面。

第 82 版修正太陽光暈上方的橫向切痕：保留照片光心，將低頻散射光置中到有完整留白的正方形貼圖，使用連續的徑向淡出，不再使用貼近光源的矩形裁切淡出。`node check-sun-halo.mjs` 檢查光暈四向覆蓋、邊界透明度及手機／桌面／4K 的實際畫面。

第 81 版將天空改為疏落的圓潤積雲，保留選定的天空藍與有明暗層次的雲海；太陽只保留從照片提取的光心與低頻散射，雲層獨立飄動。夜間增加細密的白色／淡暖白星河、小型紋理月亮、隨月相變化的月光雲海，以及偶發流星。右下選單的「島上光影」新增暫停、1、60、300、900、3600 倍時間；跨午夜會累加日期，每天的雲況、霧量、日照偏移和月相各有差異並連續過渡，人物與風速不受時間倍率加速。「即時」回到台灣時間。相關測試為 `node check-night-sky.mjs`、`node check-daily-weather.mjs`、`node check-atmosphere.mjs`。

製作工坊每次進入隨機選擇三人圍桌討論、兩人坐著操作電腦加一人站著操作工具、或原有三人面向鏡頭。每組位置在同一次停留保持固定，三人獨立呼吸、點頭、輕微轉頭和手部示意／操作，動態暫停時一併停止。房圖移除原先固定的兩張空椅，椅子採獨立圖層，坐下時用人物加椅子的完整素材替換空椅。`node check-workshop-states.mjs` 檢查三種狀態、獨立動畫與手機／4K 畫面；`node check-room-approach.mjs` 檢查各配置的兩個 PPT 入口都可抵達。影像生成來源與完整提示詞見 [工坊背景](assets/room-workshop-chair-clean-v78.md) 與 [圓潤雲層](assets/rounded-cloud-sky-v81.md)。

第 75 版支援從 `房間_編號_標題.pptx` 讀取簡報名稱，例如 `設計_1_搞定原理圖設計.pptx` 顯示「搞定原理圖設計」。房內清單、白框提示、簡報標題及投影片替代文字同步使用實際檔名；本機 PowerPoint 匯出與 GitHub 轉檔皆按前綴辨識入口，改名時沿用未變更的投影片，遇到重複前綴則停止並提示。維護方式見 [PPT/README.md](PPT/README.md)，測試為 `python check-ppt-filenames.py` 與 `node check-ppt-filename-titles.mjs`。

三位人物保留每次進房選定的固定站姿／坐姿，加入各自不同節奏的呼吸及偶爾的手腕、打字微動。坐姿只對人物上半身與雙手作連續網格微動，椅背、椅墊、雙腳與輪子保持固定；製作工坊的三人站姿也各自微動，環境動態暫停時一併停止。`node check-npc-idle.mjs` 比對 12 種人物／姿勢的呼吸、手部畫面變化與下半身固定性。

第 74 版修正中央 PCB 白框被平台遮擋圖層蓋住的問題：人物改用家具輪廓裁切，避免在白框上方重畫不透明房圖。描邊沿 PCB 板的實際外邊線與後側凹角排列。`node check-pcb-outline.mjs` 比對白框顯示／隱藏時的實際畫面，確認安東尼站立、左右坐姿下的 13 個邊緣取樣點都能看到白框，並檢查第二份簡報開啟及手機／4K 畫面；椅腳完整性另由 `node check-simulation-chair-legs.mjs` 驗證。

第 73 版依新主島底圖重新校準上層橋面與相接階梯，將博士初始落點移到橋面中央 `(500, 922)`，並縮小這段路徑的側向容許範圍，排除舊扶手上的位置。`node check-island-bridge-paths.mjs` 檢查扶手位置不可行走、四間房的實際進出，以及走動時鞋底位置沿橋面中央移動。驗証工作室改為中間兩台設備共用第二個 PPT 入口，右側螢幕開啟第三份 PPT；模擬實驗室中央 PCB 面板按四角透視重描，右側三台螢幕各自沿外框描邊、共同開啟第三份 PPT。

第 72 版改用一張完整的 2286 × 4096 透明主島底圖，修整建築與道路的拼接、島邊缺口，並移除驗証工作室門前的 PCB 殘影。停用舊建築縮圖及地面補片的覆蓋，樹草藤蔓從新底圖取樣，保留水流、螢幕、日夜光影與原入口路線。生成方式、實際生成尺寸、4K 升頻及完整提示詞見 [island-master-v72.md](assets/island-master-v72.md)。`node check-island-master.mjs` 檢查統一素材、地面透明度、四間房入口、放大與手機畫面。

模擬實驗室的左側螢幕、中央分析平台、右側螢幕依序開啟 `模擬_1.pptx`、`模擬_2.pptx`、`模擬_3.pptx`；兩張椅子連同坐姿各向外移 42 個場景像素，讓椅腳避開中央平台遮擋。製作工坊改為左側螢幕連 `製作_1.pptx`、後方雙螢幕連 `製作_2.pptx`，取消桌面白框，加入小公主、漢克及安東尼的獨立站姿與呼吸。初始站位集中在 `npc-routines.js` 的 `workshopTeam`，方便後續調整。`node check-lab-workshop-ppt-links.mjs` 檢查五個入口、人物與手機／4K 版面；`node check-simulation-chair-legs.mjs` 比對實際畫面中的完整椅腳及坐姿呼吸穩定性。

第 71 版載入小島時，塚博士預設站在設計工作室前方的上層石橋，落點為既有可行走路線上的 `(460, 918)`，可直接前往各房間。`node check-island-spawn.mjs` 檢查初始落點、四間房的連通路線與手機／桌機畫面。

第 70 版在驗証工作室新增三個獨立白框入口：左側螢幕、示波器、電源供應器，由左到右分別開啟 `PPT/驗証_1.pptx`、`PPT/驗証_2.pptx`、`PPT/驗証_3.pptx`。各入口有獨立的停留點、設備朝向及投影片快取對應。`node check-verification-ppt-links.mjs` 檢查實際點選、翻頁、返回、鍵盤及手機／4K 排版。

第 69 版依指定位置配置設計工作室的三個白框簡報入口：桌上麵包板、櫃子抽屜、右側螢幕，依序開啟 `PPT/設計_1.pptx`、`PPT/設計_2.pptx`、`PPT/設計_3.pptx`。每個入口使用各自的描邊、接近點與設備朝向，主題清單也列出三份簡報；版權書堆保留。轉檔對應集中於 `PPT/decks.json`，沿用投影片預載與無下載按鈕的顯示方式。執行 `node check-design-ppt-links.mjs` 檢查三處實際點選、檔案對應、翻頁、返回、版權入口、鍵盤與手機／4K 排版。

第 67 版將上方薄雲的目標光學雲量降至原參考的 40%，移除較弱的雲絲並保留較亮的雲團；下方雲海濃度保持原設定，太陽核心及散射保留。預設「自動風速」獨立平順變化，通常約 0.4–2.6 倍；手動拖曳風速會關閉該項自動功能，按「自動風速」可恢復。隨機風向先維持 180 秒，再用 30 秒漸變至下一方位，避免頻繁轉向。驗證包括前 150 秒風向保持穩定、自動風速連續變化、上方雲量比對、下方雲海不變，以及手機／桌機上的兩項獨立控制。

第 66 版在右下工具選單加入「雲層風場」：風速為 0–8 倍，風向角度表示吹向（0° 北／上、90° 東／右、180° 南／下、270° 西／左）。預設隨機風向會緩慢轉變；拖曳風向滑桿改為手動，按「隨機風向」可恢復。換方向或速度會沿目前位置繼續移動；0 倍停止整體風移，局部聚散仍持續。上下風向帶動天空薄雲，下方雲海保持水平，近景與遠景風速不同。`node check-wind-controls.mjs` 檢查控制項、隨機轉向、風速比例、實際雲紋位移方向、零風速、手機及桌機排版；可使用 4–8 倍快速觀察。

第 65 版保留選定的藍天與攝影雲紋，將雲層從固定天空圖拆開。`atmosphere.js` 使用連續風場、風速差、局部濃度與邊緣擴散，讓薄雲及雲海移動、聚合與消散；這是視覺模擬，不是氣象預報模型。太陽周圍的受光雲氣獨立變形，透光程度隨前方雲量改變，夜間雲層也會遮住星光。風場形變有固定上限，避免運行時間累積造成斜向拉伸；薄雲採中性白與冷色陰影，避免低透明度去背產生彩色雜邊。支援 Worker／OffscreenCanvas 的瀏覽器在背景執行雲形運算，不支援時使用快取的主執行緒版本；動態暫停會同時凍結雲形變化。啟動預覽伺服器後，依序執行 `node check-cloud-evolution.mjs`、`node check-atmosphere.mjs`，檢查連續變形、聚合消散、模擬兩小時後的風場穩定性、貼圖接縫、背景運算、遮光、遠近視差及日夜切換。時間比對畫面存於 `.preview/cloud-evolution-*-v65.png`。

第 38 版點選室內螢幕時，塚博士會走到同一通道內、距原操作點 110 個場景像素以內的可達空位，再開啟主題；已在附近時可直接開啟。抵達點及路徑都會避開固定人物，不再嘗試走進被占用的位置。`node check-room-approach.mjs` 檢查四間房、所有固定姿勢及舊路徑被擋住時的恢復。

## 操作

第二十三版讓三位工作人員各自選擇隨機任務，並保留離開房間後的位置與進度。小公主偏重麵包板試作、整理與搬運零件、回電腦確認；安東尼偏重長時間坐著分析、換螢幕比對、盤胸及踱步思考；Hank 偏重量測、檢查 PCB、核對 PASS、閱讀紀錄與調整眼鏡。三人的時間、步速與任務權重不同。

人物可以沿安全路線換桌、坐下、半起身再站立、操作電腦、拿放 PCB／平板／紀錄板、抓頭、盤胸、點頭、張望及輕微伸展。姿勢與轉向有過渡，走路有起步、減速、擺臂與雙腳變形。完整衣服網格避免切片裂開，椅面與鍵盤接觸點各自校準，道具放回桌上後保留。Hank 以原始八視圖修正為原有卡通臉型與頭身比例，維持淺藍襯衫加白色博士服。九張透明素材與內建 image_gen 提示詞見 [npc-prompts-v23.md](assets/npc-prompts-v23.md)。

`npc-routines.js` 可調整習慣、權重與時間，`npc-life.js` 管理人物及道具狀態，`npc-renderer.js` 負責完整貼圖網格、手部接觸及過渡。人物依即時位置避障；塚博士遇到工作人員會繞路，必要時對方先起身讓路再繼續工作，貓也會避開移動中的人。入口有人時另選安全站位。新增姿勢素材在點選房屋時載入，不要求手機先下載三人的全部九張圖片；直接開本機 HTML 也可使用。

第二十二版調整四間房間的人物尺度：室內博士高度由 200 提升為 280 場景單位，小公主 330、安東尼 300、Hank 310，並重新對齊桌面與站位。Hank 使用面向左上工作台的新背側姿勢、襯衫與白色博士服。三人的工作、前傾、查看與呼吸採連續變化，整個人物保留完整，沒有交替換格或衣服切片。Hank 素材及提示詞見 [npc-prompts-v22.md](assets/npc-prompts-v22.md)。

同版重新設計貓的生活節奏：慢走與小跑有起步、加速與減速，走到相連的落腳點後可以蹲身、跳上、攀爬、落地及原路下來。`cat-terrain.js` 管理島上的扶手、矮牆、屋頂樑與屋瓦，以及四間房間的桌邊／窗台；只有設定且連通的可達表面能落腳，不能任意選天空或懸崖。貓有清醒趴著、坐著、後腳抓耳、理毛、伸懶腰與睡覺，坐下約 30–65 秒、趴著 45–100 秒、睡覺 90–220 秒，停留結束後也可能繼續原地休息；使用者靠近需要讓路時例外。

貓會檢查整段移動與落腳位置是否有人，地板上繞過博士和房內工作人員；高處依表面高度及人物高度判斷。博士也會停在碰撞前，貓會繞路、退讓，或在房門附近先進屋讓出通道。進出房間會選擇沒有重疊的入口位置，保留唯一一隻貓的共用狀態。新增透明動作素材與提示詞見 [cat-actions-prompts-v22.md](assets/cat-actions-prompts-v22.md)。

| 玻璃圓頂 | 模擬實驗室 | PCB 投影、訊號完整性眼圖、電源完整性與板件熱分布 |

四間房間各有獨立的 1536 × 1024 室內圖、設備介紹、流程示意操作與博士待機圖。第八版以 EDA／PCB 為核心；第二十版整理為設計、製造交接、PCB 驗証及 SI／PI 模擬四個單一客戶主題。每個主題都有三階段示意流程；驗証完成顯示「PASS · 示範檢查項目已完成」。手機直式與橫式都可捲動內容，返回按鈕固定顯示。這些是互動示意，不會執行實際 EDA 分析。

博士以透明的正面、右側與背面素材組成 2.5D 角色。袖子、軀幹與衣襬透過同一張連續材質網格變形，避免分層旋轉時白袍露出裂縫；雙腳另外交替走動，並保留轉向、呼吸與揮手側身。待機時腳下座標不變，每隔一段隨機時間會揮手。行走以安全石板路網與廣場多邊形限制，逐步檢查腳下位置，無法走下懸崖。

雲朵從島嶼分離成獨立透明圖層，隨持續的風向飄移。瀑布改回疊加柔和細線向下流動，原圖水面保持固定；細線在水流上下端淡入淡出，落水處的水花與泡沫保持原圖靜態外觀。三棵主要樹冠保留完整底圖，再以柔和邊緣的葉片圖層搖曳，避免輪廓切割露出背景。兩個鐘面依台灣時間運轉，地面投影隨時間改變方向、長度與深淺。

島上工坊的機械手臂已改成 PCB 打樣桌；前方廣場的小 PCB 展示桌於第十八版移除，恢復石板地面。設計室圖面與玻璃圓頂投影也改為電路板。十個動態螢幕分布在工坊、驗証工作室與模擬實驗室，顯示 PCB 走線、量測波形、眼圖、板件熱分布與 PASS；驗証螢幕保留前方探針的遮擋。

小鳥數量隨機為 **0～3 隻**，每隔一段隨機時間重新決定數量，包含完全沒有鳥的空檔。小鳥各自飛過、靠近、降落、在屋頂或安全廣場停棲、轉頭／啄地／小跳，停留後飛走。博士靠近地上的小鳥時，小鳥會飛開。起飛及離場中的鳥仍計入上限，不會超過三隻。

島嶼繪製改用原始 **1536 × 2752** 圖像細節，搭配去背遮罩；相比先前 937 × 1678 素材，來源像素約增加 2.7 倍。原圖被雲擋住的少數區域使用去背素材補回，避免帶回固定雲塊。這不是重畫成 4K 或完整 3D 模型。

依互動遊戲需求，預設播放動態，即使系統開啟「減少動態效果」也不會無聲停用。需要靜止畫面時可使用畫面上的動態開關。博士首次約 4 秒後自動揮手，其後不定時揮手；胸口與頭部以約 3.6 秒週期呼吸起伏，衣襬在站立與行走時均會飄動，雙腳位置保持在安全路面。

## 驗證

第二十三版新增 `node check-npc-behavior.mjs`，以三組種子各模擬約 67 分鐘，檢查工作比例、主要動作、物品唯一狀態、家具路線、暫停、博士互讓、入口佔用及貓與人物同時活動時的碰撞。另重現安東尼從左側椅子起身、原路被博士擋住的情況，確認可以重新選擇讓路點。

`node check-npc-browser.mjs` 檢查九張素材、正面／背面／側面走路時衣服的透明孔洞、坐姿中間過渡、三房間在手機及 3840 × 2160 的完整顯示，以及直接開本機 HTML。`check-cat-browser.mjs` 同時確認只繪製修正後的 Hank 卡通素材。瀏覽器測試使用相同偵錯連接埠，請依序執行。

`node check-greetings.mjs` 讀取實際獨立語庫，測試隨機邊界值、主題與句子輪替，以及新增主題、不同句數、單一主題、單句與空語庫等編輯情況。檢查依目前語庫數量計算，無須隨增刪句子修改測試。`node check-audio.mjs` 使用本機 Chrome 檢查房名懸停／點選、手機音符按鈕、實際音訊訊號、停棲才叫、音量、靜音與分頁暫停／恢復。瀏覽器測試請依序執行，避免共用 Chrome 偵錯連接埠。

第十四版另修正正面走路擺臂時袖子與軀幹過渡過陡造成的細小透明孔洞。`check-preview.mjs` 在安全廣場明確取樣前、側、後姿勢，並在手機手勢測試前取消進屋，避免房間視窗干擾測試。

先執行 `node serve.mjs`，另一個終端機執行 `node check-rooms.mjs`。測試使用本機 Chrome，檢查四間房間的安全行走、進門轉場、設備選取、PASS 示意、離開與手機 320px／390px／橫式佈局。截圖寫入被 Git 忽略的 `.preview/`。可透過 `ISLAND_TEST_URL` 環境變數改測 GitHub Pages 網址。

第二十一版另使用 `node check-room-world.mjs` 密集檢查室內路線與家具間距，並以三組種子長時間模擬貓在五個場景的唯一位置、進出順序、六種動作、同場景叫聲及暫停。瀏覽器 `check-rooms.mjs` 驗證點地板行走、途中取消設備、抵達才開窗、關窗原地、手機／4K 完整地圖、四份實際清單下載，以及同一隻貓進出房間、在其他場景隱藏、泡泡及實際音訊訊號。

第二十二版新增 `node check-cat-behavior.mjs`：逐一往返所有屋頂、扶手、牆台與室內落腳點，檢查精確落地、人物整段碰撞、突然走入路線的人、門口讓路、加減速及較長休息時間。`node check-cat-browser.mjs` 實測屋頂跳躍、回到地板、博士與貓互讓、入口不重疊、Hank 面向左上工作台、連續微動及手機比例。三組長時間隨機模型合計涵蓋五個場景；隨機活動不保證每次短時間內造訪全部房間。

第二十版的房間測試另實際下載四份清單並核對內容，驗證單一主題、取消放大、三階段流程、圖表完成狀態及 4K 主題排版。音訊測試預設強制瀏覽器要求使用者互動；設定 `ISLAND_AUTOPLAY=allowed` 可測允許自動播放的情況，兩種情境都會檢查靜音不被後續互動覆寫。

`node check-scene.mjs` 另檢查 1440 × 1000、320 × 640、390 × 844 與 844 × 390 滿版畫布、島嶼完整顯示、工具收合、手機觸控地點與雙指縮放。

## GitHub Pages 更新

GitHub Pages 使用 `main` 分支根目錄發布。更新 HTML、CSS、JavaScript（包含 `room-world.js`、`island-cat.js`）、獨立語庫／主題內容或使用中的圖片後，提交並推送至 `main`，GitHub 會自動更新網站。所有素材均使用相對路徑。`.nojekyll` 讓網站直接以靜態檔案提供服務；`.preview/` 是本機測試資料，不會上傳。
