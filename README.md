# 塚博士的浮空島

浮空島互動測試版。純 HTML、CSS、JavaScript，沒有外部套件或網路素材。

手機與桌機測試網址：<https://mild0317.github.io/Otsuka-Island/>。手機直接以 Safari 或 Chrome 開啟即可，不需要與電腦連上相同 Wi-Fi。

## 開啟測試

直接用 Chrome 或 Edge 開啟 `index.html` 即可。請保留同一資料夾中的 CSS、`game.js`、`doctor-greetings.js`、`room-topics.js`、`life.js`、`rooms.js`、`outlines.js`、`audio.js`、兩張原圖，以及完整 `assets/` 資料夾。目前預設為滿版島景，右下角提供音符、「完整小島」與「工具」三個小按鈕；開啟工具後可看到「互動測試版 20」、音量與動態開關。已開啟舊頁面時請按 Ctrl+F5 更新。

也可以在此資料夾執行 `node serve.mjs`，開啟 <http://127.0.0.1:4173>。

第十三版在桌機左下角加入「手機掃碼探索」QR Code，掃描後開啟同一個 GitHub Pages 網站並自動呈現手機版。QR 圖是本機靜態 SVG，無須連接外部 QR 服務；手機窄螢幕與觸控裝置自動隱藏。

第十四版針對島上房屋放大時的模糊，重製四張獨立內景細節貼圖。原內景取自 937 × 1678 整島圖，現在每間屋內使用獨立 1254 × 1254 圖像，並以原室內遮罩直接繪製，避免縮回整島底圖而丟失細節。PCB、麵包板、電子零件、量測設備與木紋皆補強。動態螢幕由 128 × 80 提升為 768 × 480，半透明疊加保留底圖細節。畫布依裝置像素比繪製（最高 3 倍、總上限約 1678 萬像素），並開啟高品質取樣。已檢查 3840 × 2160 輸出；200 吋的實際效果仍取決於投影／面板輸出解析度與觀看距離。這不是整島原生 4K／8K 重建；進房後的 1536 × 1024 圖片維持原素材。四張 `assets/island-detail-*-v14.jpg` 與完整內建 imagegen 提示詞記錄於 [detail-prompts-v14.md](assets/detail-prompts-v14.md)。

## 手機版測試

同一個 `index.html` 會自動切換成手機版，支援直式畫面、觸控點選、拖曳和雙指縮放。手機版的地點、揮手、縮放按鈕皆至少 44px，並保留底部安全區。

島景使用完整瀏覽器視窗，移除固定的介紹文字、頁尾、地點清單及博士卡片。鏡頭依島嶼實際範圍計算最大完整顯示比例；工具選單預設關閉，選地點、點畫面其他位置、按關閉或 Esc 都可收起。手機橫式時工具內容可捲動。

若要用實際手機測試，讓電腦與手機連上同一個 Wi-Fi，在電腦雙擊 `start-mobile-preview.cmd`，或在此資料夾執行：

```text
node serve.mjs --host 0.0.0.0
```

手機瀏覽器輸入終端機列出的 `Phone (same Wi-Fi)` 網址。這是區域網路預覽，不會上傳到 GitHub。測試結束在終端機按 Ctrl+C 關閉；若電腦防火牆詢問，僅允許私人網路連線。

## 操作

第二十版將音樂改為預設開啟，音量維持 35%。頁面先嘗試自動播放；若瀏覽器要求使用者互動，第一次點擊、觸碰或按鍵時開始播放。手動靜音後，其他互動不會再開聲。房內與島上的音符同步。瀏覽器行為參考 [MDN 自動播放說明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)。房間移除放大按鈕與放大模式，始終完整呈現場景，島嶼本身仍可縮放。

同版新增四個客戶展示主題，每個房間只有一個發光設備入口與一個主題。點設備後切換到主題頁，可看常見問題、軟體原廠資料、可操作的 PCB 流程示意，並下載各房間專屬的 UTF-8 洽談準備清單。返回房間則回到完整場景。內容放在 [room-topics.js](room-topics.js)，主題規劃、資料內容及原廠參考見 [房間主題說明.md](房間主題說明.md)。示意圖以 SVG 繪製，可隨螢幕尺寸呈現；圖表與 PASS 為教學示意，不含實際客戶板件或分析結果。

第十九版將塚博士的招呼語移至獨立的 [doctor-greetings.js](doctor-greetings.js)，可用記事本或 VS Code 直接修改、增加或刪除句子及主題，不必改遊戲程式。目前保留原有 7 主題、56 句；詳細格式、範例與線上更新方式請見 [語庫編輯說明.md](語庫編輯說明.md)。空白與重複句子自動略過，各主題句數可不同，只有一個主題也支援。語庫透過一般 script 載入，直接開本機 HTML 仍可使用。

第十八版加入四間房間的電子工作音效：設計工作室的鍵盤輕敲、製作工坊的焊台開關與短暫焊接細聲、驗証工作室的量測提示音、模擬實驗室的資料脈衝與掃頻音。進屋、選設備、執行示意流程與完成都有對應回饋，房內也會間歇播放輕微工作聲。房間右上角音符與島上開關同步，音量共同調整；當時預設靜音，第二十版改為預設開啟。離開房間、取消流程或切到其他分頁會停止對應音效。房內不新增戶外鳥叫，背景音樂持續。聲音皆以 Web Audio 合成，無須下載音檔。

同版移除製作工坊前方的小展示桌、PCB、桌腳與陰影，補回連續石板廣場，保留前方欄杆。使用獨立高解析局部貼圖 `assets/workshop-terrace-clean-v18.jpg`，製作提示詞見 [terrace-prompts-v18.md](assets/terrace-prompts-v18.md)。

第十七版新增右下角音符開關，可切換背景音樂與鳥聲；當時預設關閉，第二十版改為預設開啟。工具選單內可調整共同音量，預設 35%。`audio.js` 以 Web Audio 在本機合成慢節奏旋律／和聲及短鳥鳴，不載入外部音檔。只有已停棲的小鳥才會隨機叫，飛行不叫；動態暫停時不新增鳥鳴。切換到其他分頁會暫停音訊，回來後恢復已開啟的聲音。音樂可在房內繼續播放。

第十七版的招呼語擴充至 **56 句**，只有一個原始範例以 HI 開頭，其他使用提問、提醒、小知識與邀請。七個軟體主題先隨機輪一遍，各主題的八句也各自洗牌；連續兩次不談同一主題，全部 56 句使用後才會再次出現相同句子。當時完整清單見 [greetings-v17.md](greetings-v17.md)；目前實際語庫改由 [doctor-greetings.js](doctor-greetings.js) 維護。

第十六版在滑鼠懸停或點選建築時，於屋頂上方顯示對應房名，與白光描邊同步。手機點建築也會顯示；名稱隨縮放及平移跟隨房子，靠近畫面邊緣會調整位置。點地面後取消選取，房內不顯示島上的房名標籤。未選取或懸停時保持隱藏。

第十五版將博士主動／自動揮手時的文字氣泡改為 21 句隨機 EDA 招呼語，涵蓋 HyperLynx、PADS、Xpedition、proFPGA、GerbTool、Valor NPI、Valor PP，各三句。每輪洗牌後逐句使用，輪完才重新洗牌，且跨輪不連續重複。氣泡顯示約 5.5 秒，依手機／桌機／4K 視窗換行與限制位置；博士開始走路或進屋時收起。當時的清單與產品定位參考見 [greetings-v15.md](greetings-v15.md)，目前內容已由第十七版的 56 句取代。

- 右下角 ☰：開啟／收起地點、縮放、跟隨、光影時間、揮手與動態控制。這些控制只在需要時顯示。
- 右下角 ⛶ 或鍵盤 R：回到放大至視窗可容納範圍的完整小島。
- 點選石板路、石階或廣場：沿安全路線走到目的地。草地、瀑布、天空與懸崖不開放行走。
- 點選四棟建築或對應按鈕：建築外輪廓會浮起白霧光邊，博士先沿安全路線走到入口，再向屋內行走、淡出，開啟該房間。
- 房間內先顯示完整場景，一個可點選設備沿物件邊緣發出白光，不顯示數字標籤。直接點物件即可進入該房間的唯一主題；「返回房間」回到場景。「主題清單」提供收合的文字入口。設備也支援 Tab、Enter 與空白鍵。主題內可執行示意流程、開啟原廠介紹及下載準備清單。按「返回小島」、Esc 或房間外的背景即可離開，博士回到安全入口位置。路上改點地面會取消進屋。
- 拖曳地圖：移動視野；滑鼠滾輪／雙指捏合／＋與－：縮放。
- ◎：跟隨博士；⛶ 或 R：回到完整小島。
- 點博士、✋ 按鈕或 G：打招呼。走路途中打招呼會等抵達後揮手。
- 地圖取得鍵盤焦點後可用方向鍵選擇附近目的地；地點按鈕也支援鍵盤。
- 「島上光影」滑桿：預覽一天中不同時段的鐘面與陰影；「即時」：回到台灣現在時間。
- 「動態 開／動態 暫停」：播放或暫停飄雲、樹木、水流、室內設備、小鳥與博士待機動畫。按揮手會恢復播放。水花固定使用原圖的靜態效果。

## 動作與素材

四棟房子由上而下對應：

| 建築 | 房間 | 室內配置 |
| --- | --- | --- |
| 鐘樓 | 設計工作室 | 平面電子工作台、麵包板、單芯跳線、散落零件、電錶、烙鐵與 EDA 螢幕 |
| 開放式木樑磚屋 | 製作工坊 | PCB 打樣、焊接、防靜電工作墊、元件料盤與電子檢視設備 |
| 左側拱窗磚屋 | 驗証工作室 | 兩台 PCB 工作站、板圖規則檢查、PASS 結果、PCB 波形量測 |
| 玻璃圓頂 | 模擬實驗室 | PCB 投影、訊號完整性眼圖、電源完整性與板件熱分布 |

四間房間各有獨立的 1536 × 1024 室內圖、設備介紹、流程示意操作與博士待機圖。第八版以 EDA／PCB 為核心；第二十版整理為設計、製造交接、PCB 驗証及 SI／PI 模擬四個單一客戶主題。每個主題都有三階段示意流程；驗証完成顯示「PASS · 示範檢查項目已完成」。手機直式與橫式都可捲動內容，返回按鈕固定顯示。這些是互動示意，不會執行實際 EDA 分析。

博士以透明的正面、右側與背面素材組成 2.5D 角色。袖子、軀幹與衣襬透過同一張連續材質網格變形，避免分層旋轉時白袍露出裂縫；雙腳另外交替走動，並保留轉向、呼吸與揮手側身。待機時腳下座標不變，每隔一段隨機時間會揮手。行走以安全石板路網與廣場多邊形限制，逐步檢查腳下位置，無法走下懸崖。

雲朵從島嶼分離成獨立透明圖層，隨持續的風向飄移。瀑布改回疊加柔和細線向下流動，原圖水面保持固定；細線在水流上下端淡入淡出，落水處的水花與泡沫保持原圖靜態外觀。三棵主要樹冠保留完整底圖，再以柔和邊緣的葉片圖層搖曳，避免輪廓切割露出背景。兩個鐘面依台灣時間運轉，地面投影隨時間改變方向、長度與深淺。

島上工坊的機械手臂已改成 PCB 打樣桌；前方廣場的小 PCB 展示桌於第十八版移除，恢復石板地面。設計室圖面與玻璃圓頂投影也改為電路板。十個動態螢幕分布在工坊、驗証工作室與模擬實驗室，顯示 PCB 走線、量測波形、眼圖、板件熱分布與 PASS；驗証螢幕保留前方探針的遮擋。

小鳥數量隨機為 **0～3 隻**，每隔一段隨機時間重新決定數量，包含完全沒有鳥的空檔。小鳥各自飛過、靠近、降落、在屋頂或安全廣場停棲、轉頭／啄地／小跳，停留後飛走。博士靠近地上的小鳥時，小鳥會飛開。起飛及離場中的鳥仍計入上限，不會超過三隻。

島嶼繪製改用原始 **1536 × 2752** 圖像細節，搭配去背遮罩；相比先前 937 × 1678 素材，來源像素約增加 2.7 倍。原圖被雲擋住的少數區域使用去背素材補回，避免帶回固定雲塊。這不是重畫成 4K 或完整 3D 模型。

依互動遊戲需求，預設播放動態，即使系統開啟「減少動態效果」也不會無聲停用。需要靜止畫面時可使用畫面上的動態開關。博士首次約 4 秒後自動揮手，其後不定時揮手；胸口與頭部以約 3.6 秒週期呼吸起伏，衣襬在站立與行走時均會飄動，雙腳位置保持在安全路面。

原始 JPG 保持不變。`assets/doctor-turnaround.png`、`assets/island-cutout.png`、`assets/cloud.png` 由內建 imagegen 依原圖製作，生成提示詞記錄於 `assets/doctor-prompt.txt` 與 `assets/environment-prompts.md`。這是從平面圖片製作的 2.5D 動畫測試版，仍保留原圖的材質陰影；新增動態投影不是完整 3D 光線追蹤，也沒有完整 3D 模型的遮擋。

舊版水流素材 `assets/island-water-clean.png` 與 `assets/water-impact-frames.png` 及提示詞 `assets/water-prompts.md` 保留為製作記錄，第四版已不再載入或使用。

第五版新增 `assets/sparrow-states.png` 與 `assets/workshop-clean.png`，皆使用內建 imagegen 製作，完整提示詞在 `assets/life-prompts.md`。`life.js` 負責樹葉、水流細線、室內設備與小鳥狀態。

第七版的五張圖片與內建 imagegen 提示詞記錄於 `assets/room-prompts.md`。島上只合成第三棟的室內家具區，其餘建築、屋頂、窗戶與島嶼沿用原圖。`rooms.js` 管理房間對話視窗、設備介紹及流程示意。

第八版新增 `assets/room-design-v8.jpg`、`assets/room-workshop-v8.jpg`、`assets/room-simulation-v8.jpg` 及 `assets/eda-island-v8.jpg`，內建 imagegen 提示詞記錄於 `assets/eda-prompts-v8.md`。驗証室沿用已有兩台 PCB／PASS 電腦的第七版圖片。舊機械場景素材保留為版本記錄，不再載入。

第九版設計室將傾斜繪圖板改為平面電子工作台，桌上包含白色麵包板、單芯跳線、IC、LED、電阻、電容、電錶及烙鐵。右側保留 EDA 工作站。流程示意改為麵包板搭建電路、電錶量測與調整，再整理原理圖銜接 PCB 佈局。室內與島上的對應圖片為 `assets/room-design-v9.jpg`、`assets/design-island-v9.jpg`，內建 imagegen 提示詞記錄於 `assets/breadboard-prompts-v9.md`。

第十版改為滿版島景與預設收合的工具選單，不更動房間圖與 EDA 內容。控制區只在使用者展開時顯示，選擇地點後自動收起。

第十一版將博士走路速度從每秒 115 調高為 200 場景座標單位，約為原來 1.74 倍。步頻沿用移動距離驅動，安全石板路與進屋流程保留。建築選取效果改為圓順轉角的暖白細線、柔和光暈、緩慢呼吸亮度與入口微光；輪廓線寬隨鏡頭縮放補償，避免放大後變成過粗白框。

第十二版改為沿建築實際屋頂、牆柱及地板邊緣繪製的粗亮白線，疊加霧邊與白光暈。視覺輪廓獨立於點選範圍與安全路線，滑鼠移到建築上也可預覽。`outlines.js` 集中保存四棟建築與十二個房間物件的描邊。房內移除所有數字標籤，進房先看場景，點選發光物件才開啟主題；返回場景或切換主題會取消未完成的示意流程。

## 驗證

`node check-greetings.mjs` 讀取實際獨立語庫，測試隨機邊界值、主題與句子輪替，以及新增主題、不同句數、單一主題、單句與空語庫等編輯情況。檢查依目前語庫數量計算，無須隨增刪句子修改測試。`node check-audio.mjs` 使用本機 Chrome 檢查房名懸停／點選、手機音符按鈕、實際音訊訊號、停棲才叫、音量、靜音與分頁暫停／恢復。瀏覽器測試請依序執行，避免共用 Chrome 偵錯連接埠。

第十四版另修正正面走路擺臂時袖子與軀幹過渡過陡造成的細小透明孔洞。`check-preview.mjs` 在安全廣場明確取樣前、側、後姿勢，並在手機手勢測試前取消進屋，避免房間視窗干擾測試。

先執行 `node serve.mjs`，另一個終端機執行 `node check-rooms.mjs`。測試使用本機 Chrome，檢查四間房間的安全行走、進門轉場、設備選取、PASS 示意、離開與手機 320px／390px／橫式佈局。截圖寫入被 Git 忽略的 `.preview/`。可透過 `ISLAND_TEST_URL` 環境變數改測 GitHub Pages 網址。

第二十版的房間測試另實際下載四份清單並核對內容，驗證單一主題、取消放大、三階段流程、圖表完成狀態及 4K 主題排版。音訊測試預設強制瀏覽器要求使用者互動；設定 `ISLAND_AUTOPLAY=allowed` 可測允許自動播放的情況，兩種情境都會檢查靜音不被後續互動覆寫。

`node check-scene.mjs` 另檢查 1440 × 1000、320 × 640、390 × 844 與 844 × 390 滿版畫布、島嶼完整顯示、工具收合、手機觸控地點與雙指縮放。

## GitHub Pages 更新

GitHub Pages 使用 `main` 分支根目錄發布。更新 `index.html`、`styles.css`、`game.js`、`doctor-greetings.js`、`room-topics.js`、`life.js`、`rooms.js`、`outlines.js`、`audio.js` 或使用中的圖片後，提交並推送至 `main`，GitHub 會自動更新網站。所有素材均使用相對路徑。`.nojekyll` 讓網站直接以靜態檔案提供服務；`.preview/` 是本機測試資料，不會上傳。
