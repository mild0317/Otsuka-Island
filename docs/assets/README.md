# 素材製作紀錄

這裡集中存放原本散在 `assets/` 的提示詞、素材來源與製作紀錄，不是網站執行時的圖片目錄。

- 網站仍引用的正式圖片保留在專案根目錄下的 `assets/`。
- 舊版、未被程式引用的圖片移到 `archive/assets/`，保留做風格與迭代參考。
- 人物八視圖及初始島圖放在 `reference/`，影片製作可據此維持角色身份。
- 部分早期紀錄中的單獨檔名指製作當時的素材名稱；尋找現存位置請查 [移動對照表](../maintenance/cleanup-manifest-2026-10-30.json)，不要把提示詞所在資料夾誤當成圖片位置。
- 星表與第三方程式的授權文字仍隨對應資料保留在 `assets/` 及 `assets/vendor/`。
