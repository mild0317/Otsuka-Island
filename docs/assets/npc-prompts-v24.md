# 後側工作姿勢素材

使用內建 imagegen，參考使用者提供的原始八視圖（角色身分與卡通比例）及 v23 工作姿勢（服裝），建立透明背景的三格素材。既有走路與表情素材維持 v23。

- `npc-princess-seats-v24.png`：小公主，長棕髮、黑上衣、白百褶裙、黑短靴。
- `npc-hank-seats-v24.png`：原始卡通 Hank，眼鏡、淺藍襯衫、白博士服、深色長褲。
- `npc-anthony-seats-v24.png`：安東尼，黑髮、眼鏡、淺色細條紋襯衫、深色長褲。

生成共用指示：1536 × 1024 透明 PNG，等距三格完整全身，同一頭部大小、鞋底基線與實際比例。三格依序為坐下、起身一半、站立工作。全都朝向左上方的工作站，背面四分之三視角，只露少許側臉；視線向下落在前方鍵盤或 PCB，手肘自然彎曲，手腕保持自然。坐姿骨盆落於隱形椅面、大腿近水平、膝蓋約 90 度、雙腳分開落地。起身時軀幹前傾、髖部上移、膝蓋逐漸伸直，手臂離開鍵盤協助平衡。站姿微向前傾，在腰部高度工作。保留原始卡通身分與頭身比例，禁止寫實化。不要畫桌椅、鍵盤、道具、文字、投影或背景。

Hank 額外要求：嚴格保留原始八視圖的大眼睛、圓臉、鼻子、黑髮與矩形眼鏡，只更換服裝，不得變成正常小頭比例的寫實人物。

程式將此左上工作姿勢鏡像為右上方向，並依椅面校準整體位置。坐姿腿部不再局部拉伸；工作人員放大約 10%，室內博士維持高度 280。
