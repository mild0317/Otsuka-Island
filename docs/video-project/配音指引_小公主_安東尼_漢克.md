# 小公主、安東尼、漢克 的配音設定

三個角色都用**微軟 Edge-TTS**（免費線上語音合成），以下列固定的聲音、語速、音高合成。任何台詞照這個設定，聲音就會跟之前的影片一致。

## 角色音色

| 角色 | 語音模型（Edge-TTS voice） | 語速 rate | 音高 pitch | 聲音特色 |
|---|---|---|---|---|
| 左移小公主 | `zh-TW-HsiaoChenNeural`（台灣女聲） | `+20%` | `+0Hz` | 清楚、自信、親切 |
| 安東尼 | `zh-TW-YunJheNeural`（台灣男聲） | `+18%` | `+18Hz` | 年輕、有活力，音調稍高 |
| 漢克 | `zh-CN-YunyangNeural`（中國男聲） | `+15%` | `-14Hz` | 較低沉、穩重的前輩感 |

- 語速、音高是在該聲音預設值上的加減，三個角色固定使用，不要改。
- 個別句子太趕可以只對那一句再放慢，例如小公主某句用 `+12%`。

## 使用方式

需要 Python 和網路連線，先安裝套件：

```
pip install edge-tts==7.3.1
```

**命令列**（一句產生一個 mp3）：

```
edge-tts --voice zh-TW-HsiaoChenNeural --rate=+20% --pitch=+0Hz --text "別怕！驗證，要左移！" --write-media 小公主_01.mp3
edge-tts --voice zh-TW-YunJheNeural   --rate=+18% --pitch=+18Hz --text "台詞" --write-media 安東尼_01.mp3
edge-tts --voice zh-CN-YunyangNeural  --rate=+15% --pitch=-14Hz --text "台詞" --write-media 漢克_01.mp3
```

**Python**：

```python
import edge_tts

VOICES = {"小公主": ("zh-TW-HsiaoChenNeural", "+20%", "+0Hz"),
          "安東尼": ("zh-TW-YunJheNeural", "+18%", "+18Hz"),
          "漢克":   ("zh-CN-YunyangNeural", "+15%", "-14Hz")}

voice, rate, pitch = VOICES["小公主"]
edge_tts.Communicate("別怕！驗證，要左移！", voice, rate=rate, pitch=pitch).save_sync("小公主_01.mp3")
```

## 注意事項

- **edge-tts 要用 7.3.1 以上**：7.2.8 會被微軟拒絕連線，出現 `403 Invalid response status`。
- 偶爾出現 `NoAudioReceived`，等幾秒重試即可。同一句一直失敗時，試著改一下標點或字（例如句尾的「！」）再試。
- **英文單字念錯**：在送去合成的文字裡，單字前後加空格或逗號、首字大寫。例如「每次bug都…」的 bug 被念成「Bow」，改成「每次 Bug，都…」就正確。字幕照原文寫就好。
- 之前影片的剪輯習慣：同一人換句停 0.35 秒、換人停 0.45 秒；整段音軌做響度正規化到 −16 LUFS。
