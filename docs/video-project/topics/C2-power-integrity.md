- 房間：模擬實驗室。
- 暫定片名：**為什麼有接電，晶片還是會不穩？**
- 目標片長：03:30（210 秒）。
- 角色：塚博士、漢克。
- 工具關聯：HyperLynx PI；現有入口 key：`labtwo`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

電源不是插上去就平均、穩定地送到每一處；要一起看路徑損失、用電需求變化與供電網路的配合。

涵蓋需求：晶片位置收到足夠電壓、避免電流擠在局部路徑、忙碌切換時仍有合適的供電支援。

貫穿案例：感測器平常待機正常，傳送資料或同時開啟多個功能時偶爾不穩。漢克先從供電條件建立可能原因，不直接宣布找到唯一根因。

## 白話詞彙與素材重點

- 電源完整性：讓元件在需要的條件下得到合適供電。
- 壓降：電經過有阻力的路徑，使用端電壓可能低於源頭。
- 去耦電容：協助應付局部快速用電需求的元件，仍需要正確選用與連接。

關鍵素材：電源網路、兩處觀察點、局部瓶頸、供電需求節拍、電容配置、A/B 條件比較。維持青綠主題。

邊界：不把 DC 電壓分布當成瞬態波形；不把供電分析直接說成完整溫度／風流分析。C3 另外說明熱與電的關係。

片尾可帶走的準備：供電來源與負載、板上供電路徑、電容與工作模式資料。
