## 要讓觀眾理解的大方向

**先講痛點**：原理圖交過來了，但板子上有幾百個零件、上千條線——怎麼知道每條線要連到哪？原理圖一改，板子會不會跟著改？兩個人能不能一起畫？

再說明佈局的四個需求，並用同一塊感測器板貫穿：

1. **原理圖串接**：零件與連線關係直接從原理圖帶進板子，不用重抄。
2. **快速連到對的地方**：還沒走線的連線會以「飛線」提示該接哪裡，照著連就不會接錯。
3. **修改自動更新**：原理圖改了，板子這邊能同步更新並標出差異，不用人工比對。
4. **協同作業**：多人可以分工處理同一塊板，彼此看得到進度。

產品（PADS／Xpedition）在說明需求之後出現，定位為「把這四件事串成同一個流程」。

## 白話詞彙與素材重點

- 電路板佈局（Layout）：決定零件放哪裡、線怎麼走。
- 原理圖串接：原理圖的零件與連線關係直接帶進佈局，兩邊保持一致。
- 飛線：還沒走線的連線，以細線提示「這兩個接點要接在一起」。
- 變更同步：原理圖修改後，佈局端更新並標示受影響的地方。
- 協同作業：多人分工處理同一個設計，避免互相覆蓋。

關鍵素材（向量繪製）：板框、零件方塊、飛線→走線動畫、原理圖 v1/v2 對照、受影響區高亮、多人分區配色、四項需求勾選清單、產品卡。

邊界：不把飛線或自動化等同「不需要工程判斷」；不深入層疊、訊號完整性等細節（B2 處理設計規則檢查，C1/C2 處理電氣分析，D3 處理跨領域改版）。不教 PADS／Xpedition 的操作步驟，不虛構產品介面、數據或客戶案例；四項功能描述在定稿前對照官方資料核對（PADS 與 Xpedition 對多人協同的支援範圍不同，措辭需確認）。

片尾可帶走的準備：確認原理圖完整可帶入、照飛線連線、改版先同步再動手。
