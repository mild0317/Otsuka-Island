- 暫定片名：**讓電路板裝得下、連得穩，也留得住修改空間**。
- 目標片長：03:30（210 秒）。
- 角色：塚博士、小公主。
- 工具關聯：Siemens PADS／Xpedition；現有入口 key：`clocktwo`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

把電路藍圖安排成可使用的實體電路板，是位置、連接、空間與製造條件一起協調的過程，不是將線接完就結束。

涵蓋需求：有限空間放得下、重要連線與供電有合適路徑、連接器及測試維修能使用、修改與製造條件有依據。

貫穿案例：感測器要裝進小外殼，接頭需要對準開孔，重要元件附近還有走線、螺絲與測試空間需要安排。

## 白話詞彙與素材重點

- Layout：把零件與連接路徑安排到實際板子上。
- 層疊：板子裡各層如何安排，不是越多層就一定越好。
- 設計規則：在尺寸、間隔與電氣條件上先約好的界線。

關鍵素材：板框、透明外殼、接頭、元件群、多層板、訊息與回流雙路徑、兩方案比較。維持霧藍主題。

邊界：不以「走線最短」當成唯一標準；不把自動佈線等同無需工程判斷。B2 處理規則風險，C1/C2 處理指定條件下的行為分析，D3 處理跨領域改版。

片尾可帶走的準備：板框與機構限制、關鍵接口需求、供電與製造條件。
