# D1｜PCB 組裝與測試製程準備

- 房間：製作工坊。
- 暫定片名：**讓產線拿到能開始準備工作的資料**。
- 目標片長：03:30（210 秒）。
- 角色：塚博士、安東尼。
- 工具關聯：Valor Process Preparation（Valor PP）；現有入口 key：`workshop`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

從設計到生產，不只是寄一包檔案；要把同一套產品資料整理成備料、組裝、檢查與測試所需的工作資訊，並能隨改版更新。

涵蓋需求：不同來源資料對齊、減少機台／文件的重複整理、組裝與檢測準備一致、換線與改版能追蹤。

貫穿案例：安東尼收到感測器板圖、零件名單、座標與組裝說明，卻發現各份檔案的版本不一致。

## 白話詞彙與素材重點

- 製程準備：正式做之前，把生產、檢查與測試要用的資料整理好。
- 零件座標：零件在板上放哪裡、朝哪個方向。
- 版本追蹤：確認資料與輸出對應哪一次設計，不只看檔名有沒有「最新」。

關鍵素材：四份資料卡、零件位號對應、方向標記、產線準備站、改版影響圖。維持銅棕主題。

邊界：不把製程準備說成產線會無人自動運作；不取代 B3 的設計可製造性確認。測試準備不等於證明所有功能正常。

片尾可帶走的準備：設計與零件／座標資料、目標組裝與檢測流程、版本與變更說明。
