## 要讓觀眾理解的大方向

**先講痛點**：板子做回來不會動，花三天才找到一條接錯的線——問題常出在一開始的原理圖。

再說明原理圖是電路的藍圖（符號代表零件、連線說明誰接誰），好的原理圖要做到三件事：**接點清楚、名稱一致、改版有紀錄**，讓接手的人不用猜，並順利交給下一站做電路板佈局。

產品（PADS／Xpedition）在說明方法之後出現，定位為「幫團隊把這段流程管好」。

## 白話詞彙與素材重點

- 原理圖：把電路接法說清楚的藍圖，不是實物照片。
- 符號／連線：零件在圖上的代表；說明哪個接點接哪個接點。
- 元件清單：準備使用哪些零件的名單，不使用 BOM 縮寫。
- 電路板佈局：決定零件放哪裡、線怎麼走。

視覺風格：淺色介面卡片（白底深藍框、黃色編號、勾選框），向量繪製的原理圖與地圖；角色為光澤公仔質感。

邊界：不把畫完原理圖等同功能已全部驗証；檢查方法由 B1（驗証工作室）展開。本片不教 PADS／Xpedition 的操作步驟，未虛構產品介面、數據或客戶案例。

片尾可帶走的準備：列出功能清單、拆成功能區塊、畫清楚原理圖。

產品來源：[Siemens Xpedition](https://www.siemens.com/en-us/products/pcb/xpedition/)；具體版本功能在定稿時核對。
