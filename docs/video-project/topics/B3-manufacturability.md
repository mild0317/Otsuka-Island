# B3｜製造可行性驗証

- 房間：驗証工作室。
- 暫定片名：**設計完成之後，還要過得了工廠這一關**。
- 目標片長：03:30（210 秒）。
- 角色：塚博士、安東尼。
- 工具關聯：Valor NPI；現有入口 key：`librarythree`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

設計在電腦中成立，仍要符合實際製板、組裝與檢測條件。提前對齊工廠能力，減少在送出資料後才來回修改。

涵蓋需求：製板細節可加工、零件與焊接／組裝空間合適、與供應商製程條件對得上，並留下可追蹤的問題與決策。

貫穿案例：感測器原型能工作，準備交工廠時才發現有些孔、間距或零件安排，與預定製程不相容。

## 白話詞彙與素材重點

- 製造可行性：不只設計得出來，也要適合實際加工與裝配。
- 製程能力：預定工廠在這個加工方式下能穩定做到的條件。
- DFM：把製造條件提早放進設計與檢查的方法。

關鍵素材：迷你工廠、三關卡、孔／間距局部、工具空間、供應商條件卡、可追蹤的問題夾。維持綠色主題。

邊界：本片產品是 Valor NPI，並非 HyperLynx 模組。D1 接續產線製程準備，D2 接續製板檔案檢查；本片不重複教兩者。

片尾可帶走的準備：板圖與元件資料、預定工廠能力、待確認的製造／組裝問題。

產品來源：[Siemens Valor NPI](https://www.siemens.com/en-us/products/pcb/valor/valor-npi/)。
