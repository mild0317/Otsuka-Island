- 房間：模擬實驗室。
- 暫定片名：**電路板為什麼會熱，怎麼提早找出風險？**
- 目標片長：03:40（220 秒）。
- 角色：塚博士、漢克。
- 使用者指定工具關聯：HyperLynx PI；現有入口 key：`labthree`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

熱不是只有某顆零件摸起來很燙；要一起看熱從哪裡來、怎麼離開、工作與環境條件，以及電與熱如何互相影響。

涵蓋需求：提早辨識發熱來源與局部瓶頸、理解板子與環境的散熱路徑、比較改善方案並對照量測條件。

貫穿案例：感測器裸板測試時狀況尚可，裝進外殼並長時間忙碌運作後，出現溫升疑慮。這只是情境，不先認定原因。

## 產品範圍：本片必讀

保留 HyperLynx PI 的指定，但不要直接寫成「PI 一套就完整求解元件、風扇、外殼與流場」。PI 的供電損耗／電流分布與板級熱或熱協同分析可相關；溫度場及散熱流程要核對使用中的版本與求解器。

現有官方資料包含 PI／Thermal co-simulation，以及 HyperLynx PI 與 Simcenter Flotherm XT 的協同案例。具體採哪一種待製作確認；目前大綱先以工具中立的熱觀念成立，不自行將主題或主產品換掉。若尚無依據，成片用概念示意，不假造 PI 的完整散熱介面。

## 白話詞彙與素材重點

- 功耗：工作時轉成熱等形式的能量消耗，不等於單純看電源額定功率。
- 熱路徑：熱從來源傳到板子、其他結構與環境的途徑。
- 電熱協同：把電與熱的相互影響納入對照或迭代，不是所有工具都以同一方式實現。

關鍵素材：裸板／外殼、熱源、傳熱箭頭、條件卡、兩種分析圖、固定色階的方案比較。維持青綠主題。

片尾可帶走的準備：功耗與工作模式、板與外殼／材料資料、環境及量測條件。
