# C1｜訊號完整性模擬

- 房間：模擬實驗室。
- 暫定片名：**讓高速訊息準時、完整地抵達**。
- 目標片長：03:30（210 秒）。
- 角色：塚博士、漢克。
- 工具關聯：HyperLynx SI；現有入口 key：`lab`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

線接通只是開始；訊息沿著板子傳遞時，形狀、時間與相互影響都可能改變。先在電腦裡比較設計，讓修正有依據。

涵蓋需求：訊息能被分辨、抵達時間合適、鄰近訊號不要互相干擾；一起考慮元件、走線、層疊與接口條件。

貫穿案例：感測器在較忙碌的傳輸模式偶爾出錯，漢克不能只用「線有沒有接上」判斷原因。

## 白話詞彙與素材重點

- 訊號完整性：訊息經過連接路徑後，還能不能被可靠辨認。
- 反射：路徑特性改變時，部分訊號能量返回，可能影響判讀。
- 餘裕：距離判斷界線還有多少空間，不是「勉強能用」就結束。

關鍵素材：傳送／接收器、訊息貼紙、示意波形、鄰近路徑、模型卡、A/B 比較。維持青綠主題。

邊界：不以漂亮眼圖代替整個領域；若出現眼圖，只說它幫助看判讀空間，不一次塞入所有專有名詞。不是所有偶發錯誤都由 SI 造成，仍需量測與其他條件佐證。

片尾可帶走的準備：關鍵接口與工作條件、板圖與層疊、可取得的模型及量測現象。
