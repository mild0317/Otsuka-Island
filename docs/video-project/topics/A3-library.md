# A3｜Library 管理

- 房間：設計工坊。
- 暫定片名：**讓團隊用對零件，也用對版本**。
- 目標片長：03:10（190 秒）。
- 角色：塚博士、小公主。
- 工具關聯：Siemens PADS／Xpedition 的元件資料流程；現有入口 key：`clockthree`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

Library 是團隊共用的零件資料資產，不只是存幾個圖案的資料夾。要管理身份、對應關係、版本與釋出，才能讓設計、採購及製造看的是同一顆零件。

涵蓋需求：減少重複建料與誤用、維持符號／焊接尺寸／實體資料一致、讓改版與替代料有依據。

貫穿案例：小公主找到三個名字相似的接頭，圖片看起來差不多，卻不是每個都適合感測器。

## 白話詞彙與素材重點

- Library：團隊共用、經過整理的零件資料庫。
- Footprint：零件在板上要焊在哪些位置的圖形。
- 釋出：經過約定檢查，可以讓團隊使用的狀態。

關鍵素材：相似接頭、四種零件身份卡、資料配對、版本差異、釋出書架。維持霧藍主題。

邊界：替代料不是名稱相似就可換；不保證所有採購、庫存與生命周期功能都內建於每一個 PADS／Xpedition 版本。

片尾可帶走的準備：料號規則、正式資料來源、建料與釋出責任分工。

產品來源：[Siemens Xpedition](https://www.siemens.com/en-us/products/pcb/xpedition/)；管理模組與版本待具體製作時核對。
