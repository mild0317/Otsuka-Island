# D2｜PCB 製造資料檢查與編輯

- 房間：製作工坊。
- 暫定片名：**出圖後再把關，讓製板資料清楚又一致**。
- 目標片長：03:20（200 秒）。
- 角色：塚博士、小公主。
- 工具關聯：WISE **GerbTool**（使用者稱 GERBER TOOL）；現有入口 key：`workshoptwo`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

製板資料是工廠實際接收的交付物。除了從設計工具匯出，還要看層別、鑽孔、比例與內容是否一致，必要修改也要有來源及追蹤。

涵蓋需求：看懂輸出資料代表什麼、找出缺漏與版本差異、確認幾何與連接資訊、受控編輯與重新交付。

貫穿案例：小公主送出感測器的製板資料夾，檔案都有，但其中的鑽孔或層別資料需要再核對。

## 白話詞彙與素材重點

- Gerber：製板常用的圖形資料格式，不等於整個設計的所有資訊。
- 鑽孔資料：告訴加工端孔的位置、尺寸等要求。
- CAM：在製造端整理、檢視與準備加工資料的工作。

關鍵素材：透明層片、孔／輪廓、版本差異、編輯記錄、回到來源的閉環。維持銅棕主題。

邊界：與 B3 的設計可製造性方向不同，本片聚焦輸出資料與受控編輯；不聲稱 GerbTool 每一種配置都包含所有功能。

片尾可帶走的準備：完整製板輸出與層別表、鑽孔與輪廓資訊、版本與變更清單。
