# B1｜原理圖驗証

- 房間：驗証工作室。
- 暫定片名：**在做成電路板前，先找出電路裡的矛盾**。
- 目標片長：03:20（200 秒）。
- 角色：塚博士、安東尼。
- 工具關聯：HyperLynx Schematic Analysis（SA）；現有入口 key：`library`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

驗証不只找一條漏接的線，而是有系統地確認電路的連接、電氣條件與元件使用方式是否相互一致，讓風險不要一路帶進板圖與樣品。

涵蓋需求：審圖範圍更完整、把元件條件與接法放在一起看、修改後可複查並留下判斷依據。

貫穿案例：感測器原理圖整理完成，安東尼準備接手，卻發現「線都連著」不代表兩端真的能合作。

## 白話詞彙與素材重點

- 電氣條件：兩端能不能用合適的電壓及訊號方式相處。
- 規則檢查：按預先約定的條件找出需要注意的位置。
- 例外：設計上刻意這樣做，必須有原因與依據，不是直接忽略警告。

關鍵素材：接口條件卡、三種檢查透鏡、可定位的疑點、處理與複查閉環。維持綠色主題。

邊界：本片不是示波器實測、不是全部功能的形式化證明，也不把 SA 等同完整電路行為模擬。

片尾可帶走的準備：原理圖與元件資料、想確認的接口／供電條件、既有疑點與例外。
