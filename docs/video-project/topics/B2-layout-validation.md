# B2｜PCB Layout 驗証

- 房間：驗証工作室。
- 暫定片名：**看起來接好了，電氣上的風險都找過了嗎？**
- 目標片長：03:20（200 秒）。
- 角色：塚博士、小公主。
- 工具關聯：HyperLynx DRC；現有入口 key：`librarytwo`。
- 共通規格：[00-production-brief.md](../00-production-brief.md)。

## 要讓觀眾理解的大方向

板子不只需要「線沒斷、間距夠」，還要依用途檢視訊息、供電、回流與干擾相關的規則風險，並知道哪些位置值得進一步分析。

涵蓋需求：人工目視難以完整掃描、一般幾何檢查之外的電氣關注、疑點分類與後續複查。

貫穿案例：小公主完成感測器板圖，一般檢查沒看到明顯短路，但關鍵訊號跨過不合適的區域，需要重新檢視路徑條件。

## 白話詞彙與素材重點

- 電氣規則：從電的工作方式出發，約定需要注意的設計條件。
- 回流路徑：電流還需要返回來源，不能只看訊息往前走的那條線。
- 進一步分析：用更詳細模型評估疑點，不把提示直接當成失效結論。

關鍵素材：板圖透明層、回流路徑、規則濾鏡、疑點定位、處理閉環。維持綠色主題。

邊界：不要用一般短路／間距 DRC 介紹取代整片；不把 HyperLynx DRC 混成 C1/C2 的完整行為模擬，也不聲稱涵蓋所有製造 DFM。

片尾可帶走的準備：板圖與層疊、關鍵訊號／電源範圍、已採用的規則與例外。

產品來源：[Siemens HyperLynx：PCB layout verification／DRC](https://www.siemens.com/en-us/products/pcb/hyperlynx/)。
