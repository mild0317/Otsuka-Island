# 浮空島影片共通製作規格

日期：2026-10-30（Asia/Taipei）。這是新對話可獨立閱讀的內容與交付簡報。

## 1. 已確定的使用者需求

- 不再以 PPT 模板為主要方案，改為 12 支教學影片。
- 每個入口代表一個知識方向，串起多種相關需求，不是一個小痛點配一支促銷短片。
- 每支至少 2 分鐘、最多 5 分鐘；目前大綱目標為 3:10–3:40。
- 觀眾不需要 EDA 背景。繁體中文、白話、台灣常用語，先講「為什麼需要」，再講概念、做法及可以得到什麼。
- 影片製作：[OpenMontage](https://github.com/calesthio/OpenMontage)；圖片素材：[Qwen-Image](https://github.com/QwenLM/Qwen-Image)；配音：[Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)。
- 統一「貼紙影片風」，帶一點可愛但維持專業。背景隨機點綴浮空島相關元素。
- 交付是真正的 `.mp4` 實體檔；依 2026-11-03 最新決定，網站點入口後在原有外框內嵌播放，保留返回房間，不自動跳轉獨立 MP4 頁或全螢幕。不是 PPT、線上剪輯器、雲端專案或只交網址。
- 本輪只建立交接文件與大綱；未生成影片、下載模型、安裝工具、修改或發布網站。

## 2. 敘事與教學方法

每片包含：生活化情境 → 這個領域想解決的一組需求 → 2–3 個核心觀念 → 一段有因果的工作流程 → 修改前後的對照 → 三句帶得走的重點。

- 每片使用同一個貫穿案例，暫定為「浮空島智慧環境感測器」：讀取環境資訊、傳送資料、裝進外殼，並有較忙碌的運作模式。它是虛構教學產品，不指定真實電路、接口速率或測試成績。
- 同一主題內要涵蓋至少三個相關需求。不要把「幾條錯誤清單」當成整個領域。
- 開頭 15–20 秒先讓觀眾認出情境，不先放產品 Logo、版本、選單或功能清單。
- 專有名詞第一次出現先用白話解釋；每片主要新術語不超過 3 個。PCB 先說「電路板」，EDA 說「協助設計與檢查電子產品的軟體工具」。
- 類比只用來幫助理解，例如送貨、交通、積木、資料護照；回到電路情境說清楚它代表什麼，不把類比當成完整物理模型。
- 多用「我們可以檢查哪些條件」「這能幫忙提早找什麼」；不寫「保證一次成功」「零錯誤」「自動解決所有問題」。
- 每片產品名稱的口播與品牌畫面原則上合計不超過 15 秒，放在方法已說清楚之後；畫面以概念示意為主，不拍成軟體操作課。
- 不虛構產品介面、客戶案例或實測數據。示意波形、熱點與改善畫面註明「教學示意」；不加沒有根據的良率、成本節省或速度百分比。
- 片尾提供三個可開始整理的資料或問題，而非只說聯絡業務。每片可獨立理解，不要求先看上一集。

## 3. 統一貼紙視覺語言

### 固定風格

- 2D／2.5D 剪貼動畫：人物與物件保留浮空島既有 3D 卡通外觀，轉成獨立貼紙，用一致白色描邊與輕柔陰影分層。
- 1080p 時白邊約 6–10 px；不要讓 PCB 線路也變成厚重白框。工程圖保留清楚、可信的層次。
- 主底色暖米白 `#F8F5ED`，文字森林綠 `#29483E`；輔助文字 `#687D70`，細分隔線 `#D8D9CE`。原有配色參考放在 `output/design-reference/ppt/island-ppt-palette-v1.png`，只沿用顏色，不沿用 PPT 任務。
- A 設計：霧藍 `#496E8A`／淡霧藍 `#E9EFF3`；B 驗証：綠 `#387054`／淡綠 `#E3EEE3`；C 模擬：青綠 `#397F7A`／淡青綠 `#DFEEEA`；D 製作：銅棕 `#A8633D`／淡米棕 `#F3E8DD`。
- 每鏡同時只強調一件事。標題短、圖像大、文字少；字幕與圖中標籤分開排，不把整段旁白貼滿畫面。
- 中文標題與字幕由合成階段排字；不要把正確文字寄望於圖片模型直接畫好。產品名稱、單位及圖例也以可編輯文字合成。
- Qwen-Image 輸出角色、物件及裝飾，再由 OpenMontage 的合成流程安排位置和動態；不是連續播放整頁截圖。

### 動作與節奏

- 角色自然呼吸、眨眼、點頭、指向重點、遞交卡片或操作工具；雙手與道具互動要看得懂。
- 貼紙入場可用輕微彈性、滑入、貼上、揭開及翻卡；避免每個字都彈跳或頻繁晃鏡頭。
- 一個大段落約 20–40 秒，拆成多個 4–8 秒鏡頭；全片通常約 25–40 個有效畫面變化，不以長時間靜止圖片湊時數。
- 線路、電流、訊息等動態用簡潔箭頭、路徑亮起或局部放大；不要只有人物在背景裡晃動。

### 浮空島隨機點綴

可選時計塔小剪影、石橋、玻璃圓頂、藤蔓、樹葉、雲朵、懸浮石塊、小工坊。每鏡以 0–2 個小元素為主，優先放角落或遠景；工程重點鏡頭可以完全不放。

「隨機」是每支與每鏡的選材、位置、微動有變化，不是每次渲染都不可重現。記錄影片種子與鏡頭種子，定稿後重製仍相同。不要遮字幕、數值或圖中走線，也不要把整座島塞進每一鏡。

| 角色 | 定位與表演 | 聲音方向 | 本機身份參考 |

| 安東尼 | 驗証與製程搭檔；拿資料、問交接條件、指出差異 | 穩定清晰的成年男聲，與博士易於區分 | `reference/characters/安東尼_3D_八視圖.png`、`assets/npc-anthony-views-v23.png` |
| 漢克 | 模擬搭檔；操作與比較方案，提出工程上的追問 | 沉穩、有活力的成年男聲，與安東尼區分 | `reference/characters/Hank_3D_八視圖.png`、`assets/npc-hank-views-v23.png` |

人物身份以原參考圖為準：髮型、五官、眼鏡、服裝、身形與辨識配色一致，不重新設計。原八視圖供本機參考，勿直接當網站公開素材。

- 人物工作姿勢可另看 `assets/npc-*-gestures-v23.png` 及 `docs/assets/npc-prompts-v23.md`；原始整張動作表要先辨識各格，不整張塞進鏡頭。
- 浮空島世界參考：`assets/island-master-4k-v72.webp`。只提取風格與點綴，不修改目前遊戲的島或房間。
- 博士負責串聯，搭檔約占 25–40% 台詞；搭檔不是只會驚嘆或犯傻的配角。D3 僅塚博士，不增加其他人物聲線。
- 每角色建立固定 Qwen3-TTS 聲音設定與試音，跨片復用；台灣華語發音要實際試聽，不把模型的 Chinese 支援當成口音保證。
- 文字稿與發音稿分開。PCB、SI、PI、Library、HyperLynx 等建立共用發音表；字幕保持正確產品拼字。
- 分句生成 WAV，保留原取樣率資訊；合成時統一重取樣與混音。用實際音檔長度排分鏡，不能只靠字數估計時長。

## 5. 製作流程與交付

1. 讀共通規格與一支大綱，展開逐字稿：說話者、台詞、畫面目標、字幕重點。
2. 將大綱中的 7 個段落拆成逐鏡分鏡；保留需求、概念、流程、案例及總結，不用片頭片尾灌水。
3. 建立角色與貼紙素材清單、視覺提示詞、固定聲音設定、名詞發音表。
4. 用 Qwen-Image 生成／編輯圖片並檢查人物一致性、邊緣、手部及技術圖像；記錄模型、版本、提示詞與種子。
5. 用 Qwen3-TTS 生成逐句配音，實際校聽，修正錯音並建立字幕時間。
6. 用 OpenMontage 組合圖片、貼紙動態、配音、字幕、背景點綴及適量音效，輸出 MP4。若目前版本沒有 Qwen 原生供應器，採外部生成檔案再匯入，不擅自改用其他模型。
7. 檢查實際 MP4：內容白話、聲音清楚、時長合格、字幕不遮圖、畫音同步、沒有損壞或缺素材，再保留成片與可重製來源。
8. 到網站整合階段，再替換指定入口、加入 D3；公開發布依使用者該輪指示處理。

### 成片規格

| 項目 | 規格 |
| --- | --- |
| 格式 | 真實 MP4；H.264 視訊、AAC 音訊、`yuv420p`，啟用 faststart |
| 尺寸與幀率 | 預設 1920×1080、16:9、30 fps；需要 4K 時另外輸出，不以升頻冒充細節 |
| 長度 | 每支實測 120–300 秒，目前企劃約 190–220 秒 |
| 配音與字幕 | 繁體中文字幕燒錄於成片，另留 SRT／VTT；字幕最多兩行，手機可辨識 |
| 音訊 | 建議整體約 −16 LUFS、true peak ≤ −1 dBTP；背景音樂不壓過人聲 |
| 構圖 | 重要文字與角色距邊緣至少約 5%；預留底部字幕區，不與原生播放控制列擠在一起 |
| 可重製來源 | 逐字稿、分鏡、素材、音軌、字幕、提示詞、種子、模型／工具版本、製片專案 |

文字長度只作估算：3 分多鐘的影片可先試約 650–950 個中文口播字，再以實際角色配音與圖解停頓調整；不要為塞入更多知識而加速成難懂的語音。

## 6. 產品配置與範圍

A1/A2/A3：Siemens PADS／Xpedition；B1：HyperLynx SA；B2：HyperLynx DRC；B3：Valor NPI；C1：HyperLynx SI；C2：HyperLynx PI；C3：HyperLynx PI 關聯的電熱／熱模擬流程，具體版本與求解器須核對；D1：Valor Process Preparation；D2：WISE GerbTool；D3：NX 等機構 CAD 與 EDA 的 ECAD／MCAD 協作。

- 使用者把 B 組統稱 HyperLynx，但 B3 指定的是 Valor NPI；主題仍放驗証工作室，產品歸屬不可寫錯。
- C3 不自行刪除或改題。腳本可先講發熱、散熱路徑與分析所需條件；若講具體溫度場、風扇、機箱流場或工具操作，必須先核對實際熱分析能力與協同工具。
- 使用者寫 GERBER TOOL，本專案既有資料與官方對應為 WISE GerbTool；片中使用正確產品拼字。
- D3 的 E/E 整合在本片依使用者舉例定義為電子／機構設計流程整合，不擴張成車用 E/E 架構、線束全流程或所有系統整合。

各片的工作範圍、不可混淆之處與來源見個別大綱及 `01-sources-and-integration.md`。
