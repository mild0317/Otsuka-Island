# V101：載入優化與網站內影片

日期：2026-11-03。依使用者回饋，保留原有網站外框來播放 A1，並改善進島等待。

- A1 在原本主題內容視窗內使用原生 `<video controls playsinline>` 播放，保留「返回房間」與標題；不離開浮空島頁面、不自動全螢幕。返回／關閉視窗會停止影片，A2 等 PPT 仍沿用翻頁控制。
- 影片檔保持原選定版本，沒有重製或重新編碼。
- 啟動由等待所有天空、人物、貓與小鳥圖片，改為只等待島與博士兩張主要圖片，合計約 2.82 MB。非必要素材在畫面開啟後背景載入；房內人物在選擇房間時載入。
- 兩張主要圖片提前 preload，設定高優先級；加上載入進度、圖片重試及明確的重新載入按鈕。
- 正式站確認原根路徑 `game.js?v=99`、`styles.css?v=99` 回傳 404，可能影響舊 HTML 快取。Pages 發布時補回根路徑相容副本，原始碼仍集中在 `src/`。
- 新增故障／慢速啟動檢查：4 Mbps、80 ms、天空及非必要圖像被阻擋時，仍可進島；主要圖片失敗時會顯示重試。加入 preload 前一次實測約 11.3 秒，不代表所有使用者連線的固定載入時間。
- 更新 A1 測試為桌面／手機內嵌播放、進度跳轉、返回停止及 A2 PPT 互不干擾。
