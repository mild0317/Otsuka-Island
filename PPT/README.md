# 房間簡報維護

支援以檔名指定畫面標題：`房間_編號_顯示標題.pptx`。

例如把第一份設計簡報改名為 `設計_1_搞定原理圖設計.pptx`，房內主題清單、白框提示及簡報標題會顯示「搞定原理圖設計」。前兩段 `設計_1` 決定入口位置；後面整段文字都是標題，標題內可繼續使用底線。設計、驗証、模擬、製作四種前綴皆適用，不必修改程式或 `decks.json`。未加標題的舊檔名仍顯示原本的「設計簡報 1」等名稱。

同一入口只保留一份 PPT，請直接重新命名原檔；若同時存在 `設計_1.pptx` 和 `設計_1_搞定原理圖設計.pptx`，轉檔會提示重複。改名後重新執行下方的本機匯出，或同步到 GitHub 發布，標題就會更新。只改名時沿用原投影片；修改內容才需要重新轉頁。

用 PowerPoint 修改、替換簡報，或依上述規則改名，再將 PPT 檔同步到 GitHub 的 main 分支。GitHub Actions 會自動解析檔名，視需要轉為 4K 投影片並發布；不用修改 HTML 或 JavaScript。只修改電腦裡的檔案還不會更新公開網站。

建議使用 GitHub Desktop 同步：在本機替換 PPT 後，提交變更並按 Push origin。製作簡報目前超過 GitHub 網頁單檔上傳的 25 MiB 限制，請用 GitHub Desktop 或 git push。其餘較小檔案也可以在 GitHub 的 PPT 資料夾使用「Add file → Upload files」上傳同名檔。發布進度在專案 Actions 頁查看，成功後重新整理網站。

本機預覽：關閉正在編輯的簡報後，在專案目錄執行 `powershell -ExecutionPolicy Bypass -File scripts/export-ppt.ps1`，再開啟本機網頁伺服器。此方式使用電腦已安裝的 PowerPoint。

入口與檔案的對應表由 `decks.json` 統一管理，本機與 GitHub 轉檔使用同一設定。未變更且已轉好的簡報會沿用原投影片；替換同名 PPT 後，會以檔案內容雜湊建立新的投影片路徑，避免顯示舊快取。四間房的各個簡報入口皆獨立對應；製作工坊已取消中央桌面入口，設計工作室左下角書堆仍是版權聲明入口。

公開網站使用 LibreOffice 自動轉檔，少數特殊字型或排版可能與 PowerPoint 有差異。投影片以靜態頁面顯示，保留文字與圖片；動畫、嵌入影片及轉場不會播放。投影片可左右翻頁、鍵盤切換或手機滑動。簡報與網站同樣公開，請只放可提供客戶閱覽的內容。
